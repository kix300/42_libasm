Dans un fichier assembleur il y a 4 partie meme si elle ne sont pas definie.
- .data -> global initialized variables
- .rodata -> global un-initialized constants
- .bss -> global un-initialized variables
- .text -> our code

DB = define byte

Aspect              32-bit (ancien)     64-bit (moderne)
Instruction syscall	int 0x80            syscall
Registres arguments	ebx, ecx, edx       rdi, rsi, rdx
Numéro write        4                   1
Numéro exit	        1	                60
Point d'entrée	    start ou _start	    _start

nasm -f elf64 helloWorld.asm && ld -o helloWorld helloWorld.o

il u a 6 registre qui passent les premier arguments au fonctions
RDI, RSI, RDX, RCX, R8, R9

RDI = PRemier parametre (destination)
RSI = Deuxieme parametre (source)
RAX = Return value + compteur
RBP = base pointeur
RSP = stack pointeur 


Registre	Rôle
