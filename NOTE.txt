RCX (64 bits = 8 bytes)
├─── ECX (32 bits = 4 bytes) ────────┐
│    ├─── CX (16 bits = 2 bytes) ──┐ │
│    │    ├─── CH (8 bits)         │ │
│    │    └─── CL (8 bits)         │ │
│    │         └─── 1 byte ────────┘ │
│    └──────────────────────────────┘ │
└───────────────────────────────────────┘

Exemple avec RCX = 0x0123456789ABCDEF :
┌────────────────────────────────────┐
│  RCX = 0x0123456789ABCDEF         │  (64 bits)
│       ECX = 0x89ABCDEF            │  (32 bits)
│            CX = 0xCDEF            │  (16 bits)
│            CH = 0xCD              │  (8 bits - high)
│            CL = 0xEF              │  (8 bits - low)
└────────────────────────────────────┘
